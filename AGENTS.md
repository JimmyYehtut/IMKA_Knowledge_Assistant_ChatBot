# IMKA Knowledge Assistant: instructions for coding agents

`CLAUDE.md` in this folder is the single source of project guidance: overview, commands, architecture and environment. Read it first; it applies to every coding agent, not only Claude Code. This file only adds what other agents need to know.

## Before you finish a change

Run the quality gates from the repository root and fix anything that fails:

```
python scripts/check.py            # backend ruff + pytest, frontend oxlint + tsc + vitest
python scripts/check.py backend    # or one side only
```

Unit tests never touch the network: OpenAI, Qdrant and Postgres are faked. If a change affects how answers show diagrams (ingestion of figures, retrieval, the answer prompt, or the chat renderer), also run the live diagram eval with the stack running. It spends OpenAI tokens:

```
cd backend
python -m evals.run_figure_eval
```

## Do not

- Edit `backend/.env`, `frontend/.env` or anything under `backend/data/` (generated by ingestion).
- Ingest, delete or patch documents in Qdrant without the user asking; use `python -m evals.audit_figures` for a dry run.
- Force-push.
